How to Install

1

From inside Cardly (fastest)

Open Cardly → Tools → Add-ons (Ctrl+Shift+A) → switch to the Marketplace tab and click Install.

2

Offline via .cardlyaddon or .zip

Click Download .cardlyaddon (or .zip) on any plugin card here, then use Install from file... inside your self-hosted Cardly instance.

3

By Add-on Code

Click Copy Code on any plugin, open Get Add-ons... in Cardly, paste the ID (like review-heatmap), and confirm the requested permissions.

FOR DEVELOPERS

Build and Publish a Cardly Add-on

Cardly plugins are plain ES modules with a manifest.json and index.js. They mount into UI slots (decks:top, decks:bottom, reviewer:actions, card:after) and declare explicit permissions.

Read SDK Docs Submit via Pull Request 
// plugins/my-addon/index.js
export default {
  onLoad(sdk) {
    return sdk.ui.mount("decks:bottom", (el) => {
      el.textContent = "Hello from Cardly!";
    });
  }
};
